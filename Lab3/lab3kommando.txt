APACHE INSTALLATION .YAML
  - name: konfig för webserver
    hosts: webservers
    become: true

    tasks:
      - name: sakerstall installation av apache
        ansible.builtin.apt:
          update_cache: true
          name: apache2

      - name: sakerstall att apache ar på
        ansible.builtin.service:
          name: apache2
          state: started


Ansible är deklarativ, så playbooken beskriver att apache2 ska vara installerat och startat.
Vid varje körning jämför modulerna det önskade läget med hur noden ser ut just nu.

Första körningen saknades apache2 på nodekea1, så apt installerade det och gav changed. 
Andra körningen hade noden redan det som krävdes, så modulerna gjorde ingenting och gav ok, vilket ger changed=0. Det är idempotens.
